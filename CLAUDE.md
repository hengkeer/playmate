## Critical Business Rules

### ⚠️ Skill Levels — NEVER access directly
```php
// WRONG — crashes on legacy data
$sport->skill_levels

// CORRECT — always safe
$sport->getSkillLevels()           // returns [{value:int, name:string}, ...]
$sport->getSkillLabel($rawValue)   // looks up label by 'value' key
$sport->normalizeSkill($rawValue)  // clamps + normalizes to 1–10
```

### ⚠️ acceptedConnections() — NOT hasMany
```php
// WRONG — hasMany prepends user_id=$id, breaks OR logic
$user->acceptedConnections()

// CORRECT — static builder
Connection::where('status', 'accepted')
    ->where(fn($q) => $q->where('requester_id', $id)->orWhere('receiver_id', $id))
```

### ⚠️ Distance Filter — in PHP, NOT SQL
SQLite lacks trig functions (`acos/cos/sin/radians`). Distance filter applied in `MatchmakingService` via `User::distanceFromUser()` after candidate fetch.

### ⚠️ N+1 Prevention — Eager Load in Controller
```php
// MatchmakingController preloads before loop:
$opponents->load('userSports.sport', 'userSports', 'reviewsReceived');
```

### ⚠️ Sports Editor Validation — `nullable`, NOT `required`
Empty sport rows must pass validation. ProfileController uses `nullable` for `sports.*.sport_id`.

### ⚠️ Score Bar UI
```blade
width: {{ $comp['weight'] > 0 ? round($comp['score'] / $comp['weight'] * 100) : 0 }}%
```
Not hardcoded `0.30` divisor.

### ⚠️ Gemini Embedding Model — Pin to `gemini-embedding-001`
```php
// CORRECT — current stable ID, 3072-dim
'embed_model' => 'gemini-embedding-001'

// WRONG — old alias `text-embedding-004` returns DIFFERENT dim, breaks cosine sim
```
`gemini-embedding-001` and `text-embedding-004` produce incompatible vectors. If index is built with one model, query MUST use the same. Re-run `php artisan rag:build` after model change.

### ⚠️ AI Assistant Controller — `ChatAssistantController`, NOT `ChatController`
`ChatController` already exists for **event group chat** (`/events/{event}/chat`). New AI assistant uses `ChatAssistantController` to avoid collision. Same for routes — `/chat` for assistant, `/events/{event}/chat` for event chat.

### ⚠️ RAG Index Path
`storage/app/private/rag/{chunks,embeddings,meta}.json` — generated by `php artisan rag:build`. **Not in git.** Re-run after `docs/*.md` changes. Listed in `.gitignore`.

## Matchmaking Engine (v2 — May 2026)

**File:** `app/Services/MatchmakingService.php`

| Component | Weight | Key Logic |
|---|---|---|
| Sport | 30% | Primary match=1.0, cross=0.75, secondary=0.5, none=0.0 |
| Skill | 30% | Band decay: diff 0→1.0, 1→0.95, 2→0.80, 3→0.60, 4→0.35, ≥5→0.15 |
| Time | 20% | Overlap ratio + day intersection, symmetric fallback |
| Distance | 15% | Continuous `exp(-d/10)` decay |
| Activity | 5% | 5 tiers: ≤3d→1.0, ≤7d→0.75, ≤30d→0.5, ≤90d→0.25, >90d→0.0 |

See `docs/matchmaking-algorithm.md` for full details.

## 5 Anti-Regression Rules

1. **Never** access `$sport->skill_levels` directly — always use `getSkillLevels()`
2. **Never** use `hasMany` for `acceptedConnections()` — use static builder
3. **Never** apply Haversine distance in SQL — use `User::distanceFromUser()` in PHP
4. **Always** eager load `userSports.sport` + `userSports` in MatchmakingController
5. **Always** use `nullable` not `required` for `sports.*.sport_id` in validation
6. **Never** use old `text-embedding-004` — always `gemini-embedding-001` (build index + query must match)
7. **Never** call `ChatController` for the AI assistant — use `ChatAssistantController`

## Coding Conventions

- Skill values: store `skill_value` (label string) + `skill_number` (1–10 int)
- Avatar storage: `storage/app/public/avatars/`
- Chat file storage: `storage/app/public/chat-files/`
- RAG index storage: `storage/app/private/rag/` (gitignored)
- Map component: `<x-map-picker>` — Leaflet `L` loaded in `<head>` before Alpine
- `preferred_days` format: `[0,1,2,3,4,5,6]` (0=Sun…6=Sat)
- Chatbot widget: `@include('partials._chatbot-widget')` injected in `layouts/app.blade.php` after login
